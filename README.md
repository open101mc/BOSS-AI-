# AI智能投递助手

BOSS直聘 AI 自动投递助手，支持自有 OpenAI 兼容接口、AI 招呼语、AI 过滤、AI 坐席、简历识别与投递统计。

## 当前版本

`v26.10.4`

## 安装

### 油猴脚本

1. 在浏览器安装 Tampermonkey。
2. 打开 Tampermonkey 管理面板，进入「实用工具」。
3. 导入 `userscript/AI智能投递助手-油猴导入包.zip`，或新建脚本后粘贴 `userscript/AI智能投递助手.user.js` 全部内容。
4. 打开 BOSS直聘求职页，确认左上角版本号为 `v26.10.4`。

### 浏览器扩展

1. 打开浏览器扩展管理页，启用「开发者模式」。
2. 选择「加载已解压的扩展程序」。
3. 选择 `extension/` 目录。
4. 打开 BOSS直聘求职页使用。

## 快速配置

1. 打开「AI配置」。
2. 填写模型供应商、模型名称、API KEY、BASE URL。
3. 点击「读取模型」和「测试连接」。
4. 保存配置并开启自有 API。
5. 点击「导入简历」，支持 BOSS 附件简历、图片、PDF、Word（DOC/DOCX/RTF）。
6. 在「偏好设置」中设置岗位、城市、月薪/日薪等筛选条件。
7. 回到「AI助手」首页，点击「开始投递」。

## 功能概览

- 自有 OpenAI 兼容 AI 接口与模型库
- AI 按岗位生成招呼语
- 招呼语送达校验与诊断
- AI 过滤评分与阈值
- AI 坐席上下文回复、防重复、手动接管检测
- AI 坐席「一直开启」模式：刷新或手动回复后自动保持开启（可在坐席右侧开关随时关闭）
- 图片 / PDF / Word 简历识别
- AI 状态分析看板
- 今日 / 本周 / 本月投递统计
- BOSS 每日 150 次沟通限制保护
- 单次投递限制 1-150
